# Password paste UI fix — 2026-09-23

- В редактор записи добавлена явная кнопка **«Вставить»** рядом с полем пароля.
- Кнопка читает буфер обмена только после явного нажатия пользователя.
- Если поле уже содержит пароль, перед заменой запрашивается подтверждение.
- Слишком длинный пароль не обрезается молча: показывается предупреждение.
- После вставки пароль снова скрывается системной маской.
- Существующий `Ctrl+V` сохранён.
- Криптографический слой, Vault v2, KDF и сервис хранения не изменялись.
